# LocalNote

Универсальный локальный голосовой конспектор: от физики и математики до инженерии, строительства, медицины, истории, бизнеса и любых других тем.

## Что сделано

- 🎙️ Захват микрофона через Web Audio + AudioWorklet, без `MediaRecorder`/WebM.
- 🔄 PCM 16-bit mono, 16 kHz передаётся напрямую в Rust; при остановке записи последний AudioWorklet-буфер принудительно дожидается доставки.
- 🧠 STT вызывается только через loopback (`127.0.0.1`, `localhost`, `::1`, `10.0.2.2`).
- 🧠 LLM сначала определяет область и подтему автоматически, а затем строит тематическую выжимку.
- 📚 Поддерживаются любые области: физика, математика, программирование, инженерия, строительство, проектирование, медицина, право, история, химия, биология, экономика, бизнес и т. д.
- 🧩 Структура динамическая: для математики могут появиться формулы и методы, для медицины — симптомы и исследования, для проекта — требования и риски, для бизнеса — решения/задачи/сроки — только если это реально было в исходнике.
- 📄 Оригинальная расшифровка сохраняется отдельно и не заменяется сводкой.
- 🔐 SQLite находится в каталоге приложения; содержимое записей шифруется AES-256-GCM.
- 🔑 Ключ выводится из пользовательского пароля через Argon2id и хранится только в памяти процесса.
- 🚫 Аудио не записывается в БД. Временный PCM хранится только в RAM и после STT удаляется.
- 🌐 Внешние AI endpoint'ы кодом блокируются.
- 🛡️ CSP включён; зависимость от CDN/npm во время работы приложения убрана. Для Android/Windows включена HTTPS-схема `tauri.localhost`, а STT/LLM вызываются из Rust, поэтому frontend не делает HTTP-запросов к loopback.

## Контракт локальных нейросетей

STT по умолчанию ожидает OpenAI-compatible endpoint:

`http://127.0.0.1:8000/v1/audio/transcriptions`

multipart-поле `file` содержит WAV, поле `model` — имя локальной Whisper-модели.

Ответ должен содержать:

```json
{"text":"распознанный текст"}
```

Допустим также ключ `transcript`.

LLM по умолчанию ожидает Ollama-compatible endpoint:

`http://127.0.0.1:11434/api/chat`

Ответ должен содержать `message.content`, причём содержимое — JSON без домыслов:

```json
{
  "topic": "…",
  "summary": "…",
  "important": ["…", "…"],
  "tags": ["…"],
  "sections": [
    {"title": "релевантный раздел", "items": ["…", "…"]}
  ]
}
```

Названия endpoint'ов и моделей можно поменять в окне настроек; кнопка «Проверить AI» дополнительно отправляет тестовый запрос локальной LLM.

## Важное ограничение

Это не «защита от взломанного устройства». Если злоумышленник получил root/полный доступ к устройству или вашему процессу, локальное шифрование не спасёт. Для обычной модели угрозы приложение не отправляет записи в облако и не хранит пароль.

Для медицины это также не заменяет врача/медицинскую документацию: локальная LLM может ошибаться. Исходная расшифровка остаётся доступной именно для проверки человеком.


## Сборка Android

`build.py` сначала инициализирует Android-проект, добавляет `RECORD_AUDIO`/`INTERNET`/`MODIFY_AUDIO_SETTINGS`, затем запускает release-сборку и ищет APK рекурсивно в стандартном Gradle output-каталоге. Это важно: патчить уже собранный APK бессмысленно.
